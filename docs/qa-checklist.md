# 验收清单 · 情绪树洞

提交或演示前照着过一遍。每条只写「怎么验」和「应该看到什么」，不写实现细节。

## A. 单文件与零外链

| # | 怎么验 | 应该看到 |
|---|---|---|
| A1 | 断网后双击 `index.html` | 页面正常打开，样式完整，四个 tab 都能点 |
| A2 | F12 → Network，刷新 | 除 `index.html` 本身外没有任何请求 |
| A3 | 运行 `python scripts/verify_single_file.py` | 输出 `PASS`，并列出体积、行数、5 个存储键 |
| A4 | 全局搜索 `http://` / `https://` / `<script src` | 0 处（README 与文档里的链接除外） |

## B. 树洞

| # | 怎么验 | 应该看到 |
|---|---|---|
| B1 | 输入框里连打 1300 字 | 停在 1200，计数器显示 `1200 / 1200` |
| B2 | 不选情绪、只写字，提交 | 成功保存，记录里情绪为空但内容在 |
| B3 | 选情绪、不写字，提交 | 成功保存，只有情绪标签 |
| B4 | 什么都不选不写直接提交 | 被拦下，输入框下方出现红色提示，不产生记录 |
| B5 | 提交后看页面 | 出现金色的自己的心声，弹出「已安放…」提示，并自动滚到这条记录 |
| B6 | 等 6 秒不操作 | 顶部语录卡自动换成下一条 |

## C. AI 劝导

| # | 怎么验 | 应该看到 |
|---|---|---|
| C1 | 输入「最近天天加班，撑不住了」 | 命中「压力」话题，先一段接情绪的话 |
| C2 | 同一条再等 1–2 秒 | 追加一段具体做法，两段不重复 |
| C3 | 输入一句没有关键词的「今天天气还行」 | 落到「轻话题」，仍然有回应，不冷场 |
| C4 | 连续输入超过 300 字 | 输入被截断在 300 字 |

## D. 广场

| # | 怎么验 | 应该看到 |
|---|---|---|

## E. 我的 / 数据

| # | 怎么验 | 应该看到 |
|---|---|---|
| E1 | 看过今日、累计、陪伴天数三格 | 数字与刚写的记录条数对得上 |
| E2 | 写 3 条记录后看环形图 | 扇区比例与情绪分布一致，标签不重叠 |
| E3 | 只有 1 天记录看柱状图 | 只画一根柱，不出现虚线补位或假趋势 |
| E4 | 点「开始呼吸」 | 圈圈按 4-4-4 节奏变化，倒计时往下走 |
| E5 | 点「导出记录」 | 浏览器下载一个 JSON，内容与本地记录一致 |
| E6 | 点「清空记录」 | 先出二次确认弹窗；确认后列表空、图表留空；用户与广场数据不受影响 |

## 已知不做的事

- 广场不做真实多设备同步（本机 localStorage）
- 密码不做真实鉴权（本地占位）
- AI 劝导不接模型（话术表）
- 不做数据加密，导出文件是明文 JSON

这些都在 README 的「已知边界与设计取舍」里写明了，验收时不计为缺陷。
